# Sleeper Bridge

Automated read-only snapshot of Sleeper dynasty league `1314667834135040000`.

- Sleeper username: `Cpablo1182`
- Data source: Sleeper public API
- Authentication: none
- Refresh: every 6 hours and on manual dispatch
